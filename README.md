# Genetic algorithm solution

Genetical algorithm for finding local minimum in polynomial functions of multiple variables

Built using python 3.13 and bitarray library

## Basic formula

$$f(x, y) = 3(x - 0.5)^2 + 2(y - 0.5)^2 \sin^2(x)$$
