# Genetic algorithm solution

Easy genetical algorithm for finding local minimum in polynomial functions of 1 variable

Built using python 3.13 and bitarray library

# Basic formula

$$f(x) = 0.2x^4 + 0.3x^3 - 6.8x^2 - 7.2x + 50$$
